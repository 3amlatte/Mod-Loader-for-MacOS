TITLE
Mod Loader for MacOS

SUMMARY
An independent mod loader for Melvor Idle 2 on macOS: loads C# mods from a mods folder, keeps failures isolated, and installs with a readable Terminal script for Apple Silicon and Intel.

DESCRIPTION
Mod Loader for MacOS is an independent loader for Melvor Idle 2. It loads existing C# mods and implements the same public mod API, so mods work without changes.

WHAT IT DOES
- Loads mods. Every mod is a folder under mods. Add a folder to install one, delete it to remove it.
- Starts first. Godot's standard override.cfg makes the loader start before the game, then the
  loader starts the game's own untouched managed code. No game file is modified or replaced.
- Keeps mods apart. A mod that fails is written to the log and skipped. The game and the other
  mods keep running.
- Stays out of the way. A blue status line at the bottom-left shows the loader version and mod
  count for 15 seconds at start, then fades out.
- Protects offline progress. Mods receive no frames while the game computes offline progress.
- One Mods button. The top-bar Mods button or F1 opens Mod Viewer (F2 also works). Mod Viewer is
  part of the loader, cannot be disabled, and is reported as a loader error if it is missing.
- Backup Saver is preinstalled. It copies saves after startup and each save, keeping the five
  newest dated backups in ~/Library/Application Support/MelvorModLoader/backups.

INSTALL (macOS)
There is no installer app. The package uses a readable .command script instead:

1. Quit Melvor Idle 2.
2. Unzip the package.
3. Double-click Install Mod Loader for MacOS.command.
   If macOS blocks it, right-click it -> Open, or run: bash install.sh
4. Start Melvor Idle 2 from Steam.

The script finds the game, copies the loader inside Melvor Idle 2.app, always installs the
required Mod Viewer 0.1.12, and re-signs the bundle ad-hoc. No game file is modified or
replaced. If the game is elsewhere:
   bash install.sh "/path/to/Melvor Idle 2.app"

Steam updates replace the app; run the script again afterwards.

MODS FOLDER
~/Library/Application Support/MelvorModLoader/mods

Mod zips contain a top-level mods folder. Extract them into:
~/Library/Application Support/MelvorModLoader

LOG
~/Library/Application Support/MelvorModLoader/ModLoaderForMacOS.log

WINDOWS
This package is macOS-only. For Windows, use Melvor Mod Loader by falorfrozen:
https://github.com/falorfrozen-cmd/MelvorModLoader

UNINSTALL
In Terminal, run: bash uninstall.sh
Mods and settings stay in Application Support.

COMPATIBILITY
The assembly name and public API names are kept for compatibility with existing mod DLLs. This
project is an independent implementation, not the original Melvor Mod Loader. Existing mods load
unchanged.

REQUIREMENTS
- macOS 14 or newer (the .NET 10 minimum), Apple Silicon or Intel.
- Melvor Idle 2 from Steam, the native macOS C# build.
